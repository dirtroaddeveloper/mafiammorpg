# Underworld Savages Backend

Laravel 11 backend for the Underworld Savages server-authoritative MMORPG.

## Structure
- `app/Domain/` — Core systems (Crimes, GTA, OC, City, Player).
- `app/Http/Controllers/` — REST API controllers.
- `routes/api.php` — REST API routes.
- `database/migrations/` — PostgreSQL schema.

## Requirements
- PHP 8.2+
- PostgreSQL
- Redis
